# Guide

AgentLens shows what coding agents cost in tokens: which skills, tools and instruction files fill the context, which of them nobody uses, and what a month of sessions costs. It reads the files that Claude Code, OpenCode, Copilot CLI and VS Code Copilot leave on your machine, and it comes as a command line, a desktop application and an MCP server for agents.

The pages are listed in reading order; the list is also the sidebar of the site.

1. [Getting started](getting-started.md): install, first commands, where the numbers come from.
2. [Sources](sources.md): which agents are read, where their files are, and what each one reports.
3. [Measured and estimated](measured-and-estimated.md): how to read a number, and why some are guesses.
4. [The analyses](analyses.md): skills, context, unused, flow, cost, efficiency and compare.
5. [Reports and export](reports-and-export.md): JSON, CSV and the offline HTML report.
6. [The desktop application](application.md): views, filters, export, updates.
7. [The MCP server](mcp-server.md): let an agent ask AgentLens itself.
8. [Exact token counts](exact-tokens.md): the one opt-in feature that sends text away.
9. [Privacy](privacy.md): what is read, what is written, what leaves the machine.
10. [Glossary](glossary.md): the terms in one place, the same entries as the application.
11. [Importing OpenTelemetry data](../telemetry.md): exports of Claude Code, Copilot CLI and VS Code Copilot.
12. [Updating the application](../updater.md): how the update check and the installation work.
